# Geopolitical Atlas

An interactive 3D globe for exploring countries, their statistics, and post-1945 history — every fact sourced,
nothing fabricated. The globe can be rendered as a flat political map or with NASA satellite, night-lights and
terrain imagery, and its brightness is adjustable. Placeholder branding; see [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for why this stack, and
[`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md) for what's real vs. known-limited.

## Quick start

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`. The `/api/news/*` endpoints won't work under plain `vite dev` (they're
Cloudflare Pages Functions) — see [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) for running those locally too.

## Regenerating the dataset

Country statistics, geometry, and identity data are generated from World Bank + Wikidata + Natural Earth at
build time, not fetched live in the deployed app:

```bash
npm run data:build
```

The post-1945 leadership record (every head of state and head of government since 1945, with terms, parties
and linked elections) is generated by the same command, and can be refreshed on its own with
`npm run data:politics` — it goes stale fastest.

See [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md) for what each source provides and its limitations.

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run build` | Type-check + production build (`dist/`) |
| `npm run data:build` | Rebuild `public/data/*` from World Bank + Wikidata + Natural Earth |
| `npm run data:politics` | Rebuild only the post-1945 leadership record (`public/data/politics/*`) |
| `npm run typecheck:pipeline` | Type-check `data-pipeline/` |
| `npm run typecheck:functions` | Type-check `functions/` (Cloudflare Pages Functions) |
| `npm run lint` | Oxlint |
